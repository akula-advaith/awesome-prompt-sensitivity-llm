# GitHub Implementations

Official and community implementations relevant to prompt sensitivity research.

- **[microsoft/promptbench](https://github.com/microsoft/promptbench)**
  Official implementation accompanying Zhu et al.'s PromptBench/PromptRobust paper — a robustness benchmark measuring LLM resilience to adversarial prompt perturbations across 8 tasks and 13 datasets.

- **[open-compass/ProSA](https://github.com/open-compass/ProSA)**
  Official EMNLP 2024 Findings implementation of ProSA, introducing PromptSensiScore (PSS) to quantify and understand prompt sensitivity.

- **[UKPLab/naacl2024-prompt-sensitivity](https://github.com/UKPLab/naacl2024-prompt-sensitivity)**
  Official code release for Lu, Schuff & Gurevych's NAACL 2024 paper on gradient-based, saliency-driven sensitivity analysis of prompts.

- **[LivNLP/prompt-robustness](https://github.com/LivNLP/prompt-robustness)**
  Implementation for evaluating the robustness of discrete prompts, including adversarial perturbation datasets for SuperGLUE tasks (CB, MNLI).

- **[IntelLabs/LLMart](https://github.com/IntelLabs/LLMart)**
  LLM Adversarial Robustness Toolkit — a general-purpose toolkit for evaluating LLM robustness through systematic adversarial testing, actively maintained with GPU/XPU support.
