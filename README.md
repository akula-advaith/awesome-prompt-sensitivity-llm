## Overview

Large Language Models (LLMs) are increasingly being used for knowledge-intensive research activities such as literature synthesis, evidence extraction, hypothesis generation, qualitative analysis, and drafting research conclusions. While these systems can provide useful assistance, their outputs may depend on how a task is expressed in the prompt.

**Prompt sensitivity** refers to changes in model behavior caused by variations in prompt wording, structure, examples, ordering, or formatting, even when the intended task remains essentially the same. Research on few-shot learning and prompt engineering has demonstrated that factors such as example selection, example ordering, formatting, and instruction design can significantly influence model performance.

For research applications, this issue is particularly important because a change in model output can go beyond differences in wording. Prompt variation may affect evidence selection, reasoning paths, factual claims, confidence, and ultimately the conclusion presented to a researcher.

This repository therefore focuses on the relationship between **prompt sensitivity and the stability of LLM-generated research conclusions**. It collects foundational and recent research, relevant datasets, software tools, GitHub implementations, and learning resources that can help researchers understand, evaluate, and mitigate prompt-induced variability.

A key idea explored in this collection is that prompt choice can be treated as part of the research measurement process. Instead of evaluating an LLM using only one carefully designed prompt, researchers can examine whether conclusions remain stable across a predefined family of semantically equivalent prompts.

- Prompt calibration
- Prompt ensembling
- Self-consistency

# Datasets

Datasets and benchmarks are important for experimentally studying how LLM behavior changes under different prompts.

This repository currently includes three relevant resources:

### PromptSET

A dataset designed for the **Prompt Sensitivity Prediction** task. It contains original questions together with multiple semantically equivalent prompt variations and labels describing whether an LLM responds consistently.

**Application:**  
Training and evaluating systems that predict whether a prompt is likely to produce sensitive behavior.

[View Datasets](datasets/datasets.md)

### Big-Bench Hard (BBH)

A collection of challenging benchmark tasks that can be used to study how LLM performance changes across different prompt templates.

**Application:**  
Evaluating prompt-template-induced changes in model performance.

[View Datasets](datasets/datasets.md)

### PromptRobust Adversarial Prompt Suite

A collection of adversarial prompt variants based on standard NLP benchmarks and different types of prompt perturbations.

**Application:**  
Stress-testing LLM robustness against character-, word-, sentence-, and semantic-level prompt perturbations.

[View Datasets](datasets/datasets.md)

**Complete dataset information:**  
[View Datasets](datasets/datasets.md)

# Tools and Libraries

The following tools and libraries can support experimentation, evaluation, prompt management, and robustness testing.

### promptfoo

An open-source tool for systematically testing and comparing prompt variations across LLM providers.

**Use in this topic:**  
Useful for comparing prompt variants and identifying prompt-induced output differences.

### lm-evaluation-harness

A framework for evaluating language models against standardized academic benchmarks.

**Use in this topic:**  
Useful for reproducible evaluation and controlling experimental conditions when comparing models and prompts.

### DSPy

A programming framework that treats prompts as optimizable and compiled artifacts.

**Use in this topic:**  
Useful for systematic prompt optimization instead of relying only on manually written prompts.

### Guidance

A library for controlling and structuring LLM generation.

**Use in this topic:**  
Useful for creating structured generation workflows and reducing uncontrolled variation.

### LangChain

A framework providing prompt templates, output parsers, and evaluation utilities.

**Use in this topic:**  
Useful for building structured LLM workflows and conducting prompt-based experiments.
